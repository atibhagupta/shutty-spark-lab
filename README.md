# Shutty: Forge Your Focus

Act as an elite front-end engineer and luxury tech UI designer. Build an ultra-premium, responsive mobile-first landing page for "SHUTTY", an interactive, social deep-work platform. 




📐 VISUAL DESIGN LANGUAGE & ANIMATION INFRASTRUCTURE




- Theme: Absolute Pitch Black (#000000) canvas background with sharp structural lines. No generic illustrations or soft wavy vectors.




- Typography: Use an oversized, , structural geometric sans-serif typeface (like Inter or SF Pro Display) for headers. All text tracks heavily left-aligned with vast margins and expansive breathing room.




- Color Palette: Pure white for primary headlines, structural mid-gray (#666666) for descriptions, and a single, blinding, razor-sharp Neon Performance Orange (#FF4500) reserved exclusively for active borders, progress lines, and metric text highlights.




- Interaction Engine: Implement smooth scroll animations using intersection observers so that section borders draw themselves in with a sleek linear line animation, and text blocks fade upward smoothly as the user scrolls.
